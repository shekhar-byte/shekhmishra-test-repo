# Discovery Express 0.15.11

Released: August 24, 2026

## Highlights

- Release notes now appear on the first launch after installation and after each upgrade.
- Update notifications include a **Release Notes** action when the ring manifest provides `releaseNotesUrl`.
- Startup and update checks use the same ring-specific public manifest.

## Improvements

- Faster startup initialization for project and notebook views.
- Clearer update status in the VS Code status bar.
- More reliable handling of Stable and Preview release rings.

## Fixes

- Prevented repeated release-note prompts when VS Code reloads the same extension version.
- Prevented release notes for a newer, not-yet-installed version from appearing at startup.
